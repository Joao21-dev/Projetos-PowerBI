# 📊 Projetos Power BI

Repositório com dashboards desenvolvidos em Power BI, parte do meu portfólio de estudos e prática em Business Intelligence e Análise de Dados.

## 📁 Projetos

### [📦 Dashboard de Gestão de Faturamento e Logística](./dashboard-logistica)
Painel de controle de entregas e devoluções, com indicadores de faturamento, performance de motoristas e motivos de devolução.

### [👥 Dashboard de Pesquisa de Satisfação dos Colaboradores](./dashboard-PesquisaRH)
Painel de análise de pesquisa de satisfação interna, cruzando dados demográficos, fonte de recrutamento e níveis de satisfação.

## 📌 Sobre

Dashboards desenvolvidos durante o curso de Power BI (8h) da **Empowerdata**, com foco em prática de modelagem de dados, DAX e storytelling visual. Serviram de base para os projetos autorais do meu portfólio, com foco no nicho de construção civil.

## 🛠️ Ferramentas

- **Power BI Desktop**
